# Knowledge

Long-term reference: past notes, archives, a knowledge base. Recalled on demand. The update replaces this map, so keep no notes in it.

## How to recall

- **Search, don't browse.** This folder can grow huge. Never walk it file by file, and never load it in advance. Search, then open only what is relevant.
- A folder here with its own `CONTEXT.md` or `_index.md` routes inside itself. Start there, then open only the notes it points to. A folder with neither → search it.
- `notes/` holds the person's own notes: durable thinking, write-ups, references.

## What does not live here

- Quick unsorted capture → `_inbox/`. A dated log → `calendar/`.
- Heavy or external knowledge (cloud storage, other vaults, code) stays outside. Only refer to it; never copy it in.

## Obsidian conventions (for every note here)

- Use `[[wikilinks]]` for internal references, not markdown links.
- Use `> [!type]` callouts for structured information.
- Use YAML frontmatter (`---` delimited) for properties.
- No tags at all: neither `tags:` in frontmatter nor inline `#tags`.
- Use `![[embeds]]` to show one note inside another.
