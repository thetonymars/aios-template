# Projects — the registry of everything ever done

One row per project, added when the project is created and never removed. Search by the `PNNNN` code: it is unique and never changes.

**What this file answers:** which projects exist and where their files are.
**What it does not answer:** status — that is the stage folder the project sits in (`projects/CONTEXT.md`).

`here` = everything is in `projects/` — find the folder by its code. A second entry means heavy files live outside (a cloud drive, another disk): write where.
