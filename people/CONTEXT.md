# Network

People & relationships. One note per person.

## Person note

File: `people/Name Surname.md`

Frontmatter (no tags — query by these fields):

```
---
type: person
role:        # what they do — e.g. designer, developer, founder
company:     # optional
location:    # optional
---
```

Body: how you met · contacts · notes.

## Finding people

Don't browse — **query**. Ask by `role` / `company` / `location`
(e.g. "who among my people is a designer?").
