# Brand

The brand of this business: identity, positioning, story, strategy, brand voice, the visual side. How a person writes is not here: voices live in `system/voices/`.

| A new fact about | Goes to |
|---|---|
| identity, positioning, differentiation, story, strategy | `<what>.md` — one file per topic: `identity.md`, `differentiation.md`, `story.md`, `strategy.md` |
| brand voice: what is known about how the brand sounds | `voice.md`; to write a text, first the voices route in `AGENTS.md` |
| colours, logo, fonts, approved series of images | `visual.md`; the images themselves stay outside this folder, `visual.md` says where |
| a dated audit of the brand | `audit-<YYMMDD>.md` — history, not the current settings |

## Rules

- A decision about the look is saved in `visual.md`, never copied into a skill.
