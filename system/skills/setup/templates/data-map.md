# Data

Rows about this business that collector skills gather from outside services (statistics, payments). Not markdown, not read at session start. Nothing here is written by hand.

Which files are here, which skill writes each one, their tables and how to see that they are fresh → `data.md` in this folder. Read it first.

## What does not live here

- Programs — they are skills in `system/skills/`. Accounts and ids — `system/skills/skill-settings.md`. Keys — `system/.secrets/`.
- Facts written for people (the channel list, prices, the numbers of the core) — the business folders next door.

## Rules

- A new source is a new skill that writes the same tables. Never split a database.
- A file that iCloud has not downloaded yet (`.<name>.icloud`) — download it first, then read.
